## 📖 درباره پروژه

وب‌سایت **خانه مدرن** یک پلتفرم حرفه‌ای برای خرید، فروش، رهن و اجاره املاک لوکس در تهران است. این پروژه با هدف ارائه تجربه‌ای مدرن، شفاف و سریع برای کاربران طراحی و پیاده‌سازی شده است.

طراحی این سایت با الهام از سبک **مینیمال لوکس** انجام شده و ترکیب رنگی سرمه‌ای، طلایی و کرم، حس اعتماد و اصالت را به کاربر منتقل می‌کند.

## ✨ ویژگی‌های کلیدی

### 🎨 طراحی
- ✅ طراحی مدرن، مینیمال و لوکس
- ✅ کاملاً **ریسپانسیو** (موبایل، تبلت، دسکتاپ)
- ✅ کاملاً **راست‌چین (RTL)** و فارسی
- ✅ فونت فارسی **وزیرمتن**
- ✅ انیمیشن‌های اسکرول ملایم
- ✅ افکت‌های Hover حرفه‌ای
- ✅ منوی موبایل کاربردی

### 🛠️ امکانات فنی
- ✅ **فرم جست‌وجوی پیشرفته** (نوع معامله، نوع ملک، منطقه، قیمت، متراژ)
- ✅ **فیلترهای پویا** روی فهرست ملک‌ها
- ✅ **مرتب‌سازی** بر اساس جدیدترین، ارزان‌ترین، گران‌ترین، متراژ
- ✅ **تغییر حالت نمایش** (شبکه‌ای / فهرستی)
- ✅ **ذخیره علاقه‌مندی‌ها** با `LocalStorage`
- ✅ **گالری تصاویر** با پیش‌نمایش
- ✅ **نقشه موقعیت ملک** با OpenStreetMap
- ✅ **فرم‌های اعتبارسنجی‌شده** (ثبت ملک، تماس، بازدید)
- ✅ **اعداد فارسی** و قالب‌بندی قیمت‌ها
- ✅ **Toast Notification** برای پیام‌های کاربری

## ⚙️ نصب و راه‌اندازی

### روش ۱ — استفاده مستقیم (ساده‌ترین)

1. فایل `index.html` را دانلود کنید
2. آن را در مرورگر خود باز کنید
3. تمام! سایت آماده استفاده است ✅

### روش ۲ — اجرا با سرور محلی

```bash
# کلون کردن پروژه
git clone https://github.com/MMN-software/portfolio.git
cd portfolio

# اجرا با Python
python -m http.server 8080

# یا با Node.js
npx serve
