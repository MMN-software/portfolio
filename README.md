# Modern Home — Luxury Real Estate Agency Website

A real estate agency website for buying, selling and renting high-end properties, written in **vanilla HTML, CSS and JavaScript**. The interface is fully Persian and right-to-left.

## Features

- **Advanced property search:** deal type, property type, area, price and size
- **Dynamic filters and sorting** (newest, price, size) on the listings page
- **Grid and list views**
- **Favourites** saved in `localStorage`
- **Property detail pages** with image gallery and an OpenStreetMap location map
- **Validated forms** for listing a property, contacting an agent and booking a viewing
- Persian numerals and localized price formatting
- Toast notifications, scroll animations and a responsive mobile menu

## Run locally

No build step. Open `index.html`, or:

```bash
npx serve .
```
